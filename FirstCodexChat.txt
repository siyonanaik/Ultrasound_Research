Yes, the “model settings” are the settings used when running MedGemma. And the classification text is a prompt—very similar to typing a question into ChatGPT—but your Colab code sends it automatically with each image.
1. What is a mask?
A mask is an image that marks exactly where an object is located.

For a BUSI breast-ultrasound image, you may have:
benign (12).png
benign (12)_mask.png
The first file is the real ultrasound image. The mask is usually a black-and-white image:
- Black pixels: outside the lesion
- White pixels: inside the lesion
Conceptually:
Ultrasound image           Mask

[breast tissue]            [black background]
[visible lesion]           [white lesion area]
[breast tissue]            [black background]
The mask was created by an expert. It is your reference answer for lesion location.

For the classification experiment, you give MedGemma only the ultrasound image—not the mask. Later, you use the mask to check whether MedGemma located the lesion correctly.

You can also convert the irregular white mask into a simple rectangle:
Mask → smallest rectangle surrounding the white area
That rectangle is your reference bounding box.
2. What are MedGemma’s “model settings”?
They are the configuration values used when MedGemma produces an answer.

For this experiment, the important settings are:
MODEL_ID = "google/medgemma-1.5-4b-it"
MAX_NEW_TOKENS = 60
DO_SAMPLE = False
TEMPERATURE = None
Meanings:
- MODEL_ID: the exact model and version being tested.
- max_new_tokens: maximum answer length.
- do_sample=False: use greedy decoding rather than randomly sampling words.
- temperature: controls randomness. It has no practical effect when sampling is disabled.
- device_map="auto": lets the library put the model on the available GPU.
- load_in_4bit=True: reduces GPU memory usage.
The important scientific rule is consistency: every image in a particular experiment must use the same settings.

MedGemma 1.5’s current default generation configuration uses greedy decoding. Google also states that the model is primarily designed for single-image tasks and that its output requires independent verification. MedGemma 1.5 model card
